Sound Locator AI · experimental
Ask about a sound at the current point in a public YouTube video. Gemini can inspect video context when supported by your selected model. Distance is an estimate of apparent scene distance, not a measured real-world distance.
Open a public YouTube video, pause near the sound, describe it, then analyze.
Requires the Gemini API key in Assistant settings and an API model that supports video understanding. The AI must state uncertainty; stereo audio and movie mixing do not reveal exact physical distance by themselves.
Multi-device audio · web app

Open the receiver web app in a full browser tab. Your main computer can keep using the World Audio extension; the other computer or a phone can receive the processed audio in its browser.

For automatic pairing, host the included web-app folder on HTTPS and run the included optional signaling server on a public HTTPS/WSS host. Enter the same server URL and 6-digit code on the TV/device. Audio still travels peer-to-peer.

Generate a code, then start pairing. Type that code into the receiver app on a TV, laptop, phone, or tablet.
