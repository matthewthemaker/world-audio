World Audio Multi-device receiver

Receive processed audio from your main World Audio computer on another laptop, tablet or phone.
Ready. Enter the 6-digit code from the main World Audio computer to pair automatically.

Connect with a session code

On the main computer, open World Audio, choose Main device, enter the same signaling-server URL, generate a code, and start automatic pairing. On this device, enter that code below. On smart TVs, use the remote to type the six digits; the layout uses large controls and does not require a QR scanner.

Manual pairing fallback

If no signaling server is configured, you can still use the original copy/paste method.

The signaling server must be deployed and reachable over WSS before short-code pairing works. This ZIP includes server source and setup notes, not a live server URL. On smart TVs, use a browser that supports WebRTC audio and WebSockets. Some TV browsers restrict background audio or autoplay; press Enable audio / TV playback after connecting. If the TV browser does not support WebRTC, this app cannot make it compatible.

Privacy and compatibility

The signaling server exchanges session codes and WebRTC connection details only; it does not receive the audio. Once connected, audio travels over a WebRTC peer connection. A STUN server helps establish the connection; some networks may still require a TURN relay, which is not included. Use a session code only with people/devices you trust.

The main device must be running the World Audio 1.1.0 extension. This receiver works in compatible desktop/mobile browsers and may work in smart-TV browsers that support WebRTC audio and WebSockets. TV browser support varies by model and firmware; no web app can bypass missing browser features.
